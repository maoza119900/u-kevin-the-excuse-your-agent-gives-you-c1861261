A deterministic Python program that writes one original excuse line — an AI agent apologizing for a shipped bug and blaming the compiler — to `entry.txt` for make.fun's "The Excuse Your Agent Gives You" bounty.

The entry it writes (139 characters, inside the gate's 1–200 window):

> Sorry about the bug — I wrote it, the compiler compiled it without a single complaint, so as far as I'm concerned, the compiler started it.

By default the file goes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write it elsewhere.

## Run it

```sh
python3 main.py
```
